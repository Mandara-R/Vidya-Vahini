# VidyaVahini – Student Commute Buddy 🚍

VidyaVahini is a real-time student transport tracking Android application developed to help students in rural areas track bus updates and receive live commute alerts.

## 📌 Problem Statement

Students in rural areas often depend on a single bus or school transport. Delays or breakdowns may cause them to miss classes or exams. VidyaVahini helps students receive live transport updates through crowdsourced bus pings and alerts.

---

## ✨ Features

- 🔐 Firebase Authentication Login
- 🚌 Real-time Bus Ping System
- 📍 ETA (Estimated Arrival Time) Updates
- ⚠️ Breakdown Alert Reporting
- 🔄 Firebase Realtime Database Integration
- 📱 Modern Android UI with Material Design
- 🚏 Route & Stop Tracking
- 👨‍🎓 Student-based Transport Monitoring

## 📂 Project Structure

- `ui/` → Screens & Fragments
- `viewmodel/` → Business Logic
- `repository/` → Firebase Operations
- `model/` → Data Models
- `utils/` → Helper Utilities

---
## ⚙️ Installation

1. Clone the repository
2. Open project in Android Studio
3. Connect Firebase project
4. Add your `google-services.json`
5. Sync Gradle
6. Run the app on emulator or Android device
